# Task 8: Simple Sales Dashboard Design

## 📊 Objective
Design an interactive sales dashboard using Power BI to visualize sales performance by product category, region, and month.

---

## 📁 Dataset
**Superstore_Sales.csv**  
- Columns used: Order Date, Region, Category, Sales, Profit

---

## 🛠 Tools Used
- Power BI Desktop
- Python (for sample dataset generation)

---

## 📌 Steps Taken

1. Imported the CSV file into Power BI.
2. Created a new column to format Order Date as "Month-Year".
3. Built the following visuals:
   - Line Chart: Sales over Months
   - Bar Chart: Sales by Region
   - Donut Chart: Sales by Category
4. Added slicers for Region and Category.
5. Used conditional formatting and custom colors for visual clarity.
6. Wrote 4 key insights based on the data.

---

## 📸 Deliverables
- `Superstore_Sales.csv` - sample dataset
- `superstore sales Insights.txt` - written insights
- Screenshot 

---

## ✅ Outcome
Gained hands-on experience in building clean, interactive dashboards for business users.
